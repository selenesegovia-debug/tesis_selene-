# Glosario

| Término | Significado |
|---|---|
| **AC** (atmósfera controlada) | Almacenamiento con O₂ reducido y CO₂ aumentado respecto del aire. Aquí: 12 % CO₂ y 6 % O₂ a 0 °C. |
| **AT** (acidez titulable) | Acidez de la fruta medida por titulación; se expresa como % de ácido cítrico. |
| **Baxlo** | Durómetro (Baxlo F0) que mide firmeza por penetración, en °Ush. |
| **BM** (bromuro de metilo) | Fumigante usado como tratamiento cuarentenario; aquí 64 g m⁻³ durante 3 h a 4,5 °C. |
| **CEPOC** | Centro de Estudios Postcosecha, Facultad de Ciencias Agronómicas, Universidad de Chile. |
| **CIELAB (L\*, C\*, h°)** | Espacio de color: luminosidad, croma y ángulo de tono. |
| **Clamshell** | Envase plástico rígido con tapa tipo concha; aquí de 125 g. |
| **Contraste planificado** | Comparación definida antes de ver los datos para responder una hipótesis concreta. |
| **emmeans** | Paquete de R que calcula medias marginales estimadas y contrastes a partir de un modelo. |
| **FirmPro** | Instrumento (HappyAgro) que mide firmeza por compresión; entrega N mm⁻¹. |
| **GLMM** | Modelo lineal generalizado mixto (aquí binomial con enlace logit). |
| **Holm** | Método de ajuste de valores *p* por comparaciones múltiples. |
| **Lobesia botrana** | Polilla del racimo de la vid; plaga cuarentenaria controlada en Chile por el SAG desde 2008. |
| **LMM** | Modelo lineal mixto: efectos fijos más un efecto aleatorio (aquí la caja). |
| **Medición base** | Cajas evaluadas a la llegada de la fruta para caracterizar el lote; no entran al análisis factorial. |
| **Origen / destino** | Momento de la fumigación: antes del almacenamiento (origen) o tras los 35 días de AC (destino). |
| **Pruina** | Capa cerosa blanquecina que cubre la baya. |
| **SAG** | Servicio Agrícola y Ganadero (Chile). |
| **SO₂** | Dióxido de azufre, usado para reducir pudriciones (en especial por *Botrytis cinerea*). |
| **SST** | Sólidos solubles totales (°Brix aproximado), en %. |
| **Tanda** | Conjunto de cajas que se fumiga en una misma operación. |
| **Testigo** | Fruta sometida al mismo tiempo y temperatura que la fumigada, pero sin BM. |
| **USDA-APHIS** | Servicio de Inspección de Sanidad Animal y Vegetal del USDA. |
